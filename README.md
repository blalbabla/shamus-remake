# Shamus 3D

Бесплатный духовный наследник игры **Shamus** (Synapse Software, 1982, Atari 8-bit): ремейк с top-down 3D-камерой.
Уровень рисуется энергетическими стенами-силовыми полями между генераторами, два вида камеры: сверху и изометрия. Все объекты собраны из 3D-примитивов, все звуки и фоновая атмосфера синтезируются кодом, лабиринты можно генерировать процедурно.

> Стек: .NET 10, C#, [Raylib-cs](https://github.com/ChrisDill/Raylib-cs) 8.1.0, xUnit.

## Быстрый старт

```bash
dotnet build
dotnet test
dotnet run --project src/Shamus.Game
```

Параметры запуска:

| Флаг | Назначение |
|---|---|
| `--maze NAME` | лабиринт: `c64` (по умолчанию), `atari`, `holmes`, `cluseau`, `marlowe`, `bond`, `random` |
| `--seed N` | зерно для `--maze random` |
| `--room N` | пропустить титульный экран и начать с комнаты N |
| `--settings` | отладка: открыть экран настроек (для скриншотов) |
| `--mute` | отключить звук |
| `--debug` | клавиши `[` и `]` переключают комнаты |
| `--view top\|iso` | вид камеры: сверху или изометрия |
| `--winsize WxH` | отладка: стартовый размер окна (проверка полей 16:9) |
| `--shot файл.png` | отладка: сохранить один кадр и выйти (вместе с `--room`, `--view`) |

## Управление

| Действие | Клавиши |
|---|---|
| Движение (8 направлений) | WASD, стрелки, нампад (8/4/2/6, диагонали 7/9/1/3; при выключенном NumLock Home/PgUp/End/PgDn) |
| Огонь | Space, Ctrl, Num 0, Num 5 |
| Карта посещённых комнат | M или Tab |
| Вид: сверху / изометрия | V |
| Пауза | P или Esc |
| Звук вкл/выкл | F2 |
| Перечитать `assets/config.json` | F5 (перезапускает текущую комнату) |

Меню: вверх/вниз, влево/вправо меняют значение, Enter подтверждает.

## Правила в двух словах

- Идите по лабиринту из 128 комнат (4 уровня), стреляйте во врагов и не касайтесь стен: они под напряжением.
- Ключи открывают замки того же цвета; закрытая дверь в комнате со скважиной открывается касанием скважины с нужным ключом.
- В pod-комнатах нужно попасть в объект через щели движущихся барьеров, после этого барьеры исчезают и появляются враги.
- Если задержаться в комнате, появится неуязвимая Тень (Shadow). В последней комнате (127) Shadow можно застрелить: это начинает новый, более трудный круг.

Подробности: [docs/DESIGN.md](docs/DESIGN.md).

## Структура репозитория

```
src/Shamus.Core/        логика игры без Raylib (лабиринты, симуляция)
src/Shamus.Game/        Raylib-фронтенд (окно, рендер, UI, звук)
tools/                  MazeExtract (ATR -> .maze), RoomCompare (сверка со скриншотами)
tests/Shamus.Core.Tests xUnit-тесты ядра
assets/                 mazes/*.maze, maps/*.map, config.json
docs/                   документация
artifacts/              исходные материалы (образ ATR, PDF, скриншоты комнат), пока не включены в коммиты
```

## Происхождение и лицензии

Shamus написан William Mataga и издан Synapse Software в 1982 году. Данные лабиринтов получены из `Shamus+.atr`
(патч Shamus+ автора slx, 2017, с конвертацией карт Commodore 64, предположительно сделанных Jack L. Thornton).
Авторские права на оригинальную игру остаются за их владельцами; в репозитории используются только данные карт и
описание формата, исходный код оригинала не переносится. Условия использования патча и конвертера см. в
`artifacts/Shamus-Source-Code/Source/README.TXT`.
